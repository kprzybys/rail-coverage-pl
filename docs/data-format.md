# Data format

Each trip lives in `trips/<YYYY-MM-DD>-<train>-<from>-<to>/`.

| File | Content |
|---|---|
| `trip.json` | train, date, UTC offset, network and device, timetable `[station, arrival, departure]` (null for pass-through), `sections`, `delays`, `excluded`, `observations`, `gps` |
| `stations.json` | `[name, lat, lon]` for every timetable station, in route order |
| `ping.csv` | `czas_iso,strata_proc,min_ms,avg_ms,max_ms` (ISO 8601 time with offset; loss %; empty RTT when loss is 100%) |
| `track.gpx` | optional GPS track, clipped to the route, lat/lon/time only |
| `bts.json` | `{"source", "sites": [{lat, lon, op, bands, place, dist_km}]}` |
| `summary.json`, `report.md`, `figures/` | generated by `railcov.report` |

Column names in `ping.csv` are Polish because the first logger wrote them that way;
they are kept for compatibility.
