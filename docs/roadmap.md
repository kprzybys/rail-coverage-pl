# Roadmap

Ideas in rough order of value. Issues and pull requests welcome for any of them.

1. **Signal and cell ID from Android.** Import logs from *Network Cell Info* or
   *G-NetTrack* (RSRP, RSRQ, cell ID, band). This answers *why* a spot is bad: no
   coverage, a handover, or a congested cell.
2. **Real track geometry.** Snap positions to OpenStreetMap railway lines instead of
   straight lines between stations.
3. **Operators side by side.** Several phones on different networks in one trip, or
   repeated trips, shown as parallel strips on the same route.
4. **Passenger forecast.** From all trips on a line: "between Opoczno and Włoszczowa
   expect two dead zones of about a minute each".
5. **Occasional throughput test.** A short, capped download every few minutes, logged
   separately, so it does not distort the ping series.
6. **On-board Wi-Fi.** Compare the train's own Wi-Fi with the phone hotspot on the
   same trip.
7. **More base station data.** Plus and Play sites from the same UKE lists, and a check
   of which permitted sites are actually on air (crowdsourced cell IDs).
